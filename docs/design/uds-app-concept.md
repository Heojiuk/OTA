# UDS 진단 애플리케이션 통합 컨셉 문서 (Multi-Platform)

## 1. 시스템 아키텍처 및 크로스 플랫폼 개요
*   **목적**: CCU(Raspberry Pi)를 게이트웨이로 삼아 차량 내부 CAN 네트워크 상의 제어기(Aurix TC275)를 진단하고 제어하는 종합 애플리케이션.
*   **지원 플랫폼**: 
    *   Windows PC (개발 및 엔지니어링용)
    *   iOS / Android 스마트폰 및 태블릿 (현장 진단용)
    *   차량용 클러스터(IVI) 디스플레이
*   **통신 토폴로지**:
    `[Client App (스마트폰/PC/클러스터)] <--- (TCP/IP / Wi-Fi, DoIP 표준 활용) ---> [Raspberry Pi 4B (CCU/Gateway)] <--- (CAN Bus) ---> [Aurix TC275 (ECU)]`
*   **프로토콜 컨셉 (DoIP)**: 
    스마트폰이나 태블릿 등 다양한 기기에서 무선 환경(Wi-Fi)으로 라즈베리파이에 접속하기 위해, 범용적이고 차량 통신 표준에 맞는 **DoIP(Diagnostics over Internet Protocol, ISO 13400)** 구조를 채택하여 TCP/IP 소켓 통신을 수행합니다.

## 2. 통합형 UI/UX 레이아웃 컨셉 (반응형 설계)

### 🍅 View 1: 대시보드 모드 (Visual Dashboard)
*   **타겟**: 스마트폰 / 클러스터 최적화
*   **컨셉**: 운전 중이나 현장에서 한눈에 직관적으로 볼 수 있는 그래픽 중심 뷰.
*   **주요 기능**:
    *   **연결 상태 패널**: Wi-Fi 연결 및 CAN Bus 상태 표시 (LED 인디케이터 스타일).
    *   **실시간 게이지 & 위젯**: 속도, 온도, 배터리 전압 등 DID 기반 실시간 데이터를 반응형 게이지와 그래프로 시각화.
    *   **원터치 퀵 컨트롤**: 큼직한 버튼 UI로 "도어 락", "팬 구동" 등의 Routine 제어.

### 🔬 View 2: 엔지니어링 뷰 (Engineering & Packet Analysis)
*   **타겟**: PC / 태블릿 최적화
*   **컨셉**: 넓은 화면을 활용한 프로토콜 디버깅 및 상세 메시지 조작 전문가 뷰.
*   **주요 기능**:
    *   **트레이스 (Trace)**: DoIP/CAN 페이로드의 타임스탬프와 Raw Hex 데이터를 실시간으로 리스트업.
    *   **수동 진단 콘솔**: 서비스 ID, Sub-function, 파라미터를 직접 입력하고 응답 분석.
    *   **DTC (고장 코드) 분석기**: 현재 고장 코드와 스냅샷 데이터 조회 및 소거.

### 📋 View 3: 시나리오 & 자동화 (Automated Scenario)
*   **타겟**: 태블릿 / PC 최적화
*   **컨셉**: 펌웨어 업데이트, EOL 검사 등 정해진 시퀀스를 원클릭으로 실행.
*   **주요 기능**:
    *   **시퀀스 플레이어**: 진단 세션 전환 → 보안 접근(Seed/Key) → 다운로드 절차 등의 복잡한 매크로 실행 및 진행률 표시.

## 3. 핵심 아키텍처 원칙: 모듈화 및 DI (Dependency Injection)
*   **100% DI 기반 설계**: 모든 서비스(통신, 로깅, UDS 파싱)와 ViewModel은 인터페이스로 추상화하여 IoC 컨테이너를 통해 주입받습니다.
*   **플랫폼 독립성**: 비즈니스 로직과 UI 레이어를 완전히 분리하여, UI 프레임워크가 바뀌더라도 핵심 로직을 재사용할 수 있도록 설계합니다.

## 4. 기술 스택 제안
*   **프레임워크**: **.NET MAUI** (Multi-platform App UI)
*   **패턴**: MVVM (CommunityToolkit.Mvvm 활용)
*   **확장**: 필요 시 **MAUI Blazor Hybrid**를 통해 고성능 웹 기반 UI 통합 가능.
